# Portfolio

React portfolio built with Vite.

## Deploy to GitHub Pages

1. Update `homepage` in `package.json` to `https://<your-username>.github.io/portfolio`
2. Update `base` in `vite.config.js` to `/<your-repo-name>/`
3. Run `npm run deploy`

Your site will be live at `https://<your-username>.github.io/portfolio`.

## Dev

```bash
npm run dev
```
